Algorithms were run sequentially in the same container, with warm imports and fresh graph/state for each timing repetition. See raw artifacts for every timing and all source hashes.

Workloads, budget and audits

Nine prospectively frozen graphs: 32-node rings (32 arcs), 64 nodes/256 arcs and 256 nodes/1,536 arcs, each using seeds 0, 1 and 2. Every graph starts with a strongly connected directed ring; larger graphs add seeded random arcs. No self loops or antiparallel pairs; each edge amount is uniformly sampled from integers 1…100. All methods receive exactly the same capacities and minimize remaining debt without new credit, preserving each node's signed net position. Cycles uses the upstream default unit-weight min-cost max-flow solver.

LedgerLoops settings: horizon 500 simulated ticks, delays 1…5 ticks, retry interval 50, max path 100, search budget 256 and a 250,000-message admission cutoff; in-flight work drains afterward. No final run hit the message cutoff. Negative ring results are retained: Random DFS seed 0 cleared nothing within the fixed window, while the Cycles reference cleared 192 units. Search is finite and contention can prevent completion.

Every completed cycle and final ledger was independently replayed; edge capacities and all node net positions reconcile. Cycles results additionally passed a no-negative-cycle certificate for minimum retained debt. All timing repeats preserved the same ledgers and communication counts. Relevant limitations

  • The Cycles baseline is its public educational notebook core run locally, not a benchmark of the hosted cycles.money product or its current production code, proving, encryption, TEE, chain finality or settlement.
  • The LedgerLoops algorithms are route-bearing research simulations: nodes use local balances and received messages, but tokens reveal paths/visited identities. They are not the photographed app's distinct neighbour-private hashlock protocol, and this is not a privacy proof.
  • LedgerLoops runtime includes protocol serialization, reservations and scheduler overhead; Cycles runtime includes graph construction and its global solver. These are actual local implementation costs, not equal-role production latencies.
  • LedgerLoops communication measures exact compact JSON envelopes encoded, queued and decoded by the adapter. The reliable model has no ACK/retransmission implementation; TCP/TLS/HTTP, deployment, replicated bilateral storage, user approvals, faults and input distribution are excluded.
  • Cycles has no protocol transport to instrument here, so its messages/wire bytes are unmeasured. Its mean input and output payloads on the 256-node graphs are 71.9 KiB and 56.5 KiB; these are serialization sizes, not measured network traffic.
  • Only three synthetic graph seeds, static capacities and three timing repeats per seed: no real-business workload, arrivals, losses, crashes, hostile peers or statistically representative performance claim.
  • Comfort clearing can increase gross debt while lowering discomfort. The pictured comfort settings and the cancellation-only benchmark evaluate different functions.
