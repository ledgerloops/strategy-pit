Primary plotted quantity:
  (gross debt in the same accepted stream without clearing - actual gross debt)
  / (gross debt in that reference - minimum gross debt under fixed hard grants).

This is final-snapshot clearing potential, not cumulative cleared invoice value.
Original undirected trustlines include zero-balance helper links and are counted
once in the x-axis denominator. Actual JSON application messages include
discovery, rejection, prepare, commit and cleanup. Initial data distribution,
external transaction injection and unimplemented network headers/ACKs are excluded.

All graph generation and scoring are offline. Actors use own links and received
neighbor messages. The simulator serializes initiators and settlement; it is not
a production deployment or a concurrency/fault/privacy proof.
